# Sajam Knjiga - OISISI Projekat

Projektni zadatak iz predmeta Osnovi informacionih sistema i softverskog inženjerstva (OISISI) - sistem za upravljanje podacima sajma knjiga.

## Autori
* **Student 1:** Lana Kuzminac
* **Student 2:** Dražen Petrović

## Tehnologije
* Konzolna aplikacija (`ConsoleAppClient`) i osnovna logika (`Core`)
* Čuvanje podataka putem CSV fajlova

## Pokretanje
1. Klonirati repozitorijum.
2. Otvoriti rješenje (`.sln`) u Visual Studio okruženju.
3. Pokrenuti projekat `ConsoleAppClient`.
